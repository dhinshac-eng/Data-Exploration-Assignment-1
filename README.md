# Excel Assignment 1 – Data Exploration

## 📌 Project Overview
This repository contains my completed Excel assignment on data exploration using Microsoft Excel. The project demonstrates basic spreadsheet analysis, the use of Excel formulas, and the creation of additional columns from existing data.

## 📂 Dataset
The dataset contains product-related information, including:
- Product ID
- Product Name
- Brand Name
- Price
- Quantity
- Product Category

## 🔍 Tasks Performed
As part of this assignment, I:
- Calculated the **Total Price** for products.
- Counted the total number of products.
- Calculated the **Average**, **Minimum**, and **Maximum** prices.
- Created a **Price Range** column based on product prices.
- Extracted the **Day**, **Month**, and **Country Code** from the Product ID.
- Generated summary calculations using Excel formulas.

## 🛠️ Excel Functions Used
- `SUM()`
- `SUMIF()`
- `COUNT()`
- `COUNTIF()`
- `AVERAGE()`
- `MIN()`
- `MAX()`
